# Search Button Accessibility Demo

A synthetic React before-and-after example of an icon-only search button with and without an accessible name.

## Live demo

https://rony-890.github.io/search-button-accessibility-demo/

## Scope

Based on one limited 1280px pricing-page observation where a header search button appeared unnamed in markup and Lighthouse and axe-core flagged it as a candidate. This is not a full-site audit, a confirmed screen-reader impact, a WCAG failure, or a live service implementation.

## Run and check

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```
